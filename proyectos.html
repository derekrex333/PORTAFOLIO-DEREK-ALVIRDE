Impacto de las Recesiones en Ventas de Automóviles

📊 9 visualizaciones 📅 Datos 1980-2023 📉 Análisis económico

Análisis exploratorio de datos para estudiar cómo los periodos de recesión económica afectan las ventas de automóviles. Se analizaron variables macroeconómicas como PIB, desempleo y gasto publicitario.

Insight: Durante periodos de recesión las ventas muestran caídas significativas y mayor volatilidad, indicando una fuerte relación entre el mercado automotriz y el ciclo económico.
